# 内分泌·体重管理 · 10月1日对比提要

## 主标题：深析——减重药"特殊人群"怎么用：老年、肌少症、妊娠、儿童、肝肾功能不全

> **比对基线**：2026-09-30【当前版】| **来源等级**：⭐⭐⭐ 库内整合深析

10月1日（国庆）内分泌无新发布。对《肥胖患者长期体重管理及药物指南2026》做**深析**：主流减重药在**特殊人群**中的用法，是最容易被忽略、也最容易出错的部分。

---

## 一、⭐ 老年及肥胖性肌少症

| 维度 | 要点 |
|------|------|
| 原则 | ⭐ **减重宜缓不宜快、宜少不宜多**；优先预防**营养不良、肌少症** |
| 生活方式 | 饮食**提高营养密度**；有氧+**抗阻**，避免瘦体重显著下降 |
| ⭐ 药物选择 | 首选 **GLP-1 RA**；合并心血管/肾脏 → 优先**司美格鲁肽/替尔泊肽**；**肌少症高风险 → 优先替尔泊肽**；注射不耐受 → 口服 GLP-1 RA |
| 监测 | 从小剂量起始，配合运动+蛋白质补充，监测营养/肌少症及心肝肾功能 |
| 奥利司他 | 注意脂肪泻、维生素缺乏；合用抗癫痫药/胺碘酮/环孢素需监测浓度 |

## 二、⭐ 围妊娠期

| 阶段 | 要点 |
|------|------|
| **孕前** | 积极体重管理，早期用药尽早达标；⭐ 首选 **GLP-1 RA**；计划妊娠或发现妊娠 → **立即停药** |
| **妊娠期** | ⭐ **以饮食和运动为主，不建议使用减重药物** |
| **产后** | 合理膳食+尽早运动+**母乳喂养≥6个月**；⭐ **哺乳期不推荐减重药** |

## 三、⭐ 儿童青少年

- 药物**仅**用于"经强化生活方式干预仍无法控制体重/改善合并症"的**中重度**肥胖儿童/青少年；**超重人群不建议**
- ⚠️ 中国**暂无获批**儿童青少年减重适应证的药物；用药需充分知情同意，**小剂量起始**，不超成人耐受剂量

## 四、⭐ 肝肾功能不全

| 药物 | 调整 |
|------|------|
| **替尔泊肽** | ⭐ 肝肾功能不全（含终末期肾病）**无需调整剂量**（重度受损经验有限）|
| **司美格鲁肽** | 轻中度无需调整 |
