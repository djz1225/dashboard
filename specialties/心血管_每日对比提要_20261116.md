## 二、本期新增（人群／设计 → 终点与数值 → 机制 → 临床落点）

### 2.0 ⭐⭐⭐ aficamten（MYQORZO）MAPLE-HCM 数据写入美国说明书

**人群与设计**：Ⅲ 期、多中心、随机、双盲、双模拟、活性对照试验，在**有症状梗阻性肥厚型心肌病（oHCM，obstructive hypertrophic cardiomyopathy）成人**中比较 aficamten 单药与标准治疗 β 受体阻滞剂美托洛尔（metoprolol）单药；主要终点为**峰值摄氧量（pVO₂，peak oxygen uptake）自基线至第 24 周的变化**（Cytokinetics 2026-11-16 通稿，⭐⭐⭐）。

**终点与数值**：达到主要终点，疗效在**全部预设亚组**（含新诊断、未治疗人群）一致；**6 项次要终点中 5 项**显著改善——NYHA（纽约心功能分级）、KCCQ-CSS（堪萨斯城心肌病问卷临床总评分）、NT-proBNP（N 末端 B 型利钠肽前体）、Valsalva 动作后 LVOT-G（左心室流出道压差）、LAVI（左心房容积指数）。总体不良事件率两组相近；差异 >5% 者为 aficamten 组高血压、美托洛尔组头晕（⭐⭐⭐通稿逐字）。⚠️ **pVO₂ 与各次要终点的具体差值未取回，待说明书 MAPLE-HCM 节数值确认，本期不写幅度。**

**机制与边界**：变构、可逆的心脏肌球蛋白抑制剂，降低心肌收缩力与左心室流出道梗阻；本次为**标签补充**，**不新增适应症人群**——适应症仍为「有症状 oHCM 成人，改善功能能力与症状」（首发依据 SEQUOIA-HCM，2025-12 批准）。

|---|---|
| 启动前 LVEF（左心室射血分数）<55% | **不推荐启动** |
| 治疗中 LVEF <50% 且 ≥40% | **减量** |
| LVEF <40%，或出现心衰症状／临床恶化 | **中断给药** |
| 超声心动图 | 治疗前及全程均须做，监测收缩功能不全 |
| 合用或停用 CYP（细胞色素 P450）抑制剂／诱导剂 | **2–8 周内**复查 LVEF 并调量 |
| 剂型与频次 | 5／10／15／20 mg 片，每日一次 |
| 分发路径 | 仅经 **MYQORZO REMS（风险评估与缓解策略）计划**：医师、患者、药房均须登记，批发商只供认证药房 |

### 2.1 ⭐⭐⭐ 《心力衰竭患者容量管理中国专家共识（2026）》：从「干体重」转向「最优容量状态」

**来源**：中国老年医学学会心电与心功能分会等，《临床心血管病杂志》2026；42(10):769-784，**DOI 10.13201/j.issn.1001-1439.2026.10.001**（原文可定位，⭐⭐⭐ 一级；操作数值经 2026-11-10 医脉通解读转述，⚠️ 三级，已比对摘要级表述，逐条待原文复核）。**目标改写**：不再单纯追求「干体重」，改为维持个体化「**最优容量平衡状态**」——消除淤血同时保住有效循环血量与器官灌注，避免过度利尿致低血压、肾损伤、电解质紊乱。**评估三步法**（Ⅰ 类推荐，C 级证据）：① 病史＋症状体征＋体重与尿量变化；② 利钠肽、尿钠、POCUS（即时超声，Ⅱa 类推荐，B 级证据）、无创充血监测；③ 复杂或危重者用有创／无创血流动力学确证。

| 操作节点 | 具体阈值／剂量 |
|---|---|
| 静脉袢利尿剂后 2 h 尿量 | **≥150 mL/h** 为反应良好 |
| 给药后 2 h 尿钠 | **<50–70 mmol/L** 为反应不足 |
| 重症心衰初始静脉袢利尿剂 | 可增至常规 **1.0–2.5 倍**；抵抗时单次剂量翻倍＋静脉推注联持续泵入 |
| 序贯肾单位阻断 | 袢利尿剂＋噻嗪类／MRA（盐皮质激素受体拮抗剂）／血管加压素 V₂ 受体拮抗剂／乙酰唑胺 |
| 血液超滤 | **200–300 mL/h**，24 h **≤5000 mL**；严重 AKI（急性肾损伤）、高钾或 pH<7.2 转血透或 CRRT（连续性肾脏替代治疗） |
| 合并急性脑梗死 | 收缩压维持 **130–150 mmHg**，急性期避免快速强效利尿，多数不常规扩容 |
| 合并电解质紊乱 | 血钠<135 mmol/L 分型处理；血钾<3.5 mmol/L 仍须先解淤血并补钾，**目标 4.0–5.0 mmol/L** |

**临床落点**：利尿反应从此有「2 小时判读点」；既往「观察一天再看」与本共识不符。

### 2.3 ⭐⭐⭐ Lp(a) 首个 Ⅲ 期结局试验 Lp(a)HORIZON 阴性：降 78.4%，主要不良心血管事件（MACE）零获益

**随机 8,350 例、疗效分析 8,322 例**已确诊 ASCVD（动脉粥样硬化性心血管疾病）且 Lp(a)（脂蛋白(a)）≥70 mg/dL 成人，pelacarsen **80 mg 皮下注射每月一次** vs 安慰剂，中位随访 4.7 年：12 个月 Lp(a) 降 **78.4%**（安慰剂升 3.2%）；主要终点（心血管死亡／非致死性心梗／非致死性卒中／紧急血运重建）**12.3% vs 12.1%，HR 1.02（95% CI 0.90–1.15），P=0.76**；基线 Lp(a)≥90 mg/dL 亚组 HR 1.00（0.87–1.15）；因不良事件停药 **20.6% vs 7.5%**（⭐⭐⭐ *NEJM* 2026-11-07 在线，Cho L 等，**DOI 10.1056/NEJMoa2610159**；AHA（美国心脏协会）2026 late-breaking 同步报告）。⚠️ 亚组 HR 与停药率系经会议摘要页（⭐⭐ 二级）交叉核对，*NEJM* 表 2／表 3 原值**待逐字复核**；结论以主要终点为准——**阴性，无获益**。**落点**：Lp(a) 仍无获批靶向药，且「降得下来」≠「事件降得下来」；高 Lp(a) 者当前仍靠 LDL-C（低密度脂蛋白胆固醇）达危险分层目标、控压、戒烟。⚠️ 同场 ZEUS（ziltivekimab）亦阴性（hs-CRP（高敏 C 反应蛋白）降 64%，3 点 MACE（主要不良心血管事件）17.6% vs 17.7%）；本条属 **2026-11-07 事件、11-15 基线未覆盖**，按补录处理，若早期次已写请以早期数值为准。

## 四、临床行动清单（本期新增）

1. **（§2.0）可以说「美国说明书已写进头对头数据」，不能说「新增适应症」**：适应症仍为有症状 oHCM 成人改善功能能力与症状。
2. **（§2.0）开方即过 LVEF 三闸**：启动前 <55% 不启动；随访 <50% 且 ≥40% 减量；<40% 或出现心衰症状中断。合用／停用 CYP 抑制剂或诱导剂后 **2–8 周**复查 LVEF。
3. **（§2.0）先完成 REMS 登记再发药**：医师、患者、药房三方登记，未认证药房不得发药；门诊首诊同步完成患者登记。
4. **（§2.1）利尿效果改为 2 小时判读**：静脉袢利尿剂后 2 h 尿量 <150 mL/h 或尿钠 <50–70 mmol/L 即判不足，进入「剂量翻倍＋持续泵入 → 序贯肾单位阻断 → 加药 → 超滤」阶梯，不再「等一天」。
5. **（§2.1）两条硬线**：超滤 200–300 mL/h、24 h ≤5000 mL；低钾时**先解淤血、同步补钾至 4.0–5.0 mmol/L**，不因离子异常延误利尿。
6. **（§2.2）三处房颤处方回查**：单用阿司匹林预防卒中者改抗凝；无依据的 DOAC 减量回查说明书条件（超说明书减量 Ⅲ B）；高龄（含极高龄）患者仅在试验未涵盖等情形下才考虑超说明书低剂量（Ⅱb C），不得自行按年龄停药或减量；具体阈值与选药原则须以指南原文为准（待核）。
7. **（§2.3）不向高 Lp(a) 患者许诺「降 Lp(a) 就少事件」**：pelacarsen 降 78.4% 而事件无获益（HR 1.02，P=0.76）。
