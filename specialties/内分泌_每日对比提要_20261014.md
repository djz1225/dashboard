# 内分泌·体重管理指南追踪 · 10月14日对比提要

## 主标题：ADA/EASD 2026 共识"早期联合" + EASD 2026 减重药新数据 + JAMA"多模式终身管理"

> **比对基线**：2026-10-13【当前版】| **来源等级**：⭐⭐⭐ 国际共识/顶刊/顶级会议（⚠️解读）

10月14日内分泌**无国内新指南发布**。本期整合三条主线：**ADA/EASD 2026 共识报告的"早期联合"主张**、**EASD 2026 减重药新数据**，以及 **JAMA "GLP-1 不是肥胖治疗全部"** 的多模式呼吁。

---

## 一、⭐ ADA/EASD 2026 共识（10/2 发布）：从"降糖"转向"整体管理"

| 维度 | 要点 |
|------|------|
| ⭐ 核心转向 | 报告焦点从**"高血糖管理"**扩展到**"T2D 及其共病的整体管理"** |
| ⭐ 早期联合 | 主张**尽早（甚至确诊时）使用 SGLT2i 和/或 GLP-1 类**，以获器官保护、改善长期预后 |
| ⭐ 更早联合 | 合并 **CVD / CKD / 心衰**者，应考虑**更早联合** SGLT2i + GLP-1 |
| 体重目标 | 超重/肥胖者以**减重 ≥10%** 为目标，**有望实现 T2D 缓解**；任何时点缓解均带来长期获益 |
| 饮食 | 优先**地中海饮食**（T2D + ASCVD）；**不推荐**用膳食补充剂降糖 |

> 含义：降糖路径从"二甲双胍起步、逐步加药"**前移到"确诊即考虑 SGLT2i/GLP-1 器官保护"**。

## 二、⭐ EASD 2026（9/28–10/2 米兰）减重药新数据

| 药物 | 关键数据 |
|------|------|
| ⭐ **口服司美格鲁肽（减重版）** | 平均减重 **17%**；**>1/3** 受试者减重 **>20%**（OASIS 4，64 周）|
| ⭐ **CagriSema**（GLP-1/胰淀素双受体激动剂）| 平均减重 **22.7%**；约 **1/4** 受试者减重 **>30%** |
| 意义 | 为肥胖**长期管理**注入循证支撑；减重幅度逼近代谢手术区间 |

## 三、⭐ JAMA（10 月）：GLP-1 不是肥胖治疗的全部

| 项 | 内容 |
|------|------|
| ⭐ 核心观点 | 肥胖是**慢性、复发性疾病**，药物只是**综合终身照护的一部分**，而非"短期减重即解决" |
| ⭐ 证据 | 世卫组织证据汇总：**GLP-1 + 强化行为治疗（IBT）** 的减重、心血管代谢改善与生活质量获益**优于单纯药物** |
| 实践 | 药物 + 营养 + 运动 + 行为 + 长期随访，才是最优模型 |

## 四、⚠️ GLP-1 全程管理要点（10 月综述）

| 阶段 | 要点 |
|------|------|
| 起始 | 评估适用性、设定现实目标、评估基线营养与运动状态 |
| 用药中 | **肌肉保护**（足量蛋白 + 抗阻训练）、副作用管理、代谢指标监测 |
| 停药 | 提前规划**停药后维持**策略，防体重反弹 |
