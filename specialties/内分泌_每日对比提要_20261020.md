10月20日内分泌·体重管理领域**无新指南发布**。今日实质信息来自管线侧而非指南侧：**10/10–10/16 一周内三件事同框**——Biomea 口服 GLP-1 **BMF-650** Ⅰ 期阳性、Verdiva **终止**口服 ecnoglutide 的 Ⅱ 期**减重维持**研究、安进为 **maridebart cafraglutid** 注册 Ⅲ 期**自动注射笔**试验。加上 **survodutide** 于 10/1 在 **NEJM** 正式见刊、礼来 **nisotirostide（NPY2 受体激动剂）** Ⅰ 期数据 10/3 见刊，一条"药物形态之争已经进入淘汰赛"的线索成型。具体数据以原文为准。

## 一、⭐⭐ 一周三件事：口服赛道的"分化"比"突破"更值得记

| 事件 | 主体 / 阶段 | 结果 | 定性 |
|------|-------------|------|------|
| ① **BMF-650** | Biomea Fusion，**口服 GLP-1**，**Ⅰ 期** | **阳性**（公司口径） | 口服小分子再进一员 |
| ② **口服 ecnoglutide** | Verdiva，**Ⅱ 期·减重维持** | **终止** | 口服多肽在"维持"场景折戟 |
| ③ **maridebart cafraglutid** | 安进，**注册 Ⅲ 期** | 启动**自动注射笔**试验 | 给药装置成为竞争维度 |

> ⚠️ 解读：三条消息合起来说明一件事——**口服 GLP-1 的难点不在"降体重"，在"维持"**。诱导期数据好看不难，难的是停药或切换后体重回弹曲线的控制。②的终止恰是最有价值的信息：它划出了这条赛道的实际死亡谷。⚠️ 三则均为企业公告/监测周报口径，**具体例数、剂量、主要终点与终止原因待原文（公司公告 / ClinicalTrials 登记）确认**。

## 二、⭐⭐ survodutide 10/1 见刊 NEJM：双激动剂在"最难的合并人群"落定

| 项 | 内容 |
|------|------|
| 期刊与时间 | **《新英格兰医学杂志》，2026-10-01**；**DOI: 10.1056/NEJMoa2607219** |
| 药物机制 | **GLP-1 / 胰高血糖素（GCGR）双受体激动剂**，**每周一次**皮下注射 |
| 人群 | 超重或肥胖（BMI≥27）合并 **2 型糖尿病**成人 |
| 研究定位 | 为"肥胖 + T2D"这一减重最难获益人群提供**正式期刊发表的疗效与安全性证据** |
| 观察维度 | 体重、**血糖控制（HbA1c）**、胃肠道不良反应、停药率、其他代谢指标 |
| ⚠️ 待原文确认 | 具体减重百分比、HbA1c 降幅、剂量组设置、停药率数字（本文不代引二手百分比） |

> ⚠️ 解读：机制合理 ≠ 优效。survodutide 的价值在于把 GCGR 这条"增加能量消耗、同时改善脂肪肝"的路径，放到了一个**降糖药必须交代血糖安全**的人群里验证。对临床的实际含义是：**双激动剂的选择题，从此要多看一项"合并 T2D 时的减重幅度折损"**——这与 10/19 讨论的瑞他鲁肽 18.8% 是同一个考点。

## 三、⭐⭐ nisotirostide：第一次有人正面回答"GLP-1 之上还能加什么"

| 项 | 内容 |
|------|------|
| 药物 | **nisotirostide**，礼来在研肽类，**神经肽 Y2 受体（NPY2R）选择性激动剂** |
| 定位 | 设计为**叠加（add-on）于 GLP-1 受体激动剂治疗之上**，而非替代 |
| 发表 | **2026-10-03** 在线发表于 **《Molecular Metabolism》**；披露发现与**首次人体（Ⅰ 期）**数据 |
| 临床前 | 小鼠中与 GLP-1 受体激动剂联用显示**协同减重** |
| 意义 | 减重药物研发从"换靶点做单药"扩展到"**给已用 GLP-1 的人加一层**" |

> ⚠️ 解读：这是赛道逻辑的一次转向。此前所有玩家都在争"谁的分子更强"；nisotirostide 提出的是**"平台化叠加"**——GLP-1 变成基础设施，后续增量靠 add-on。对临床的远期意味：未来患者的方案可能不是"换药"，而是"**在 GLP-1 之上加一味**"，届时疗效评价、费用与安全性归因都会更复杂。⚠️ Ⅰ 期数据为健康志愿者/小样本，**剂量、减重幅度与安全性待原文确认**。
