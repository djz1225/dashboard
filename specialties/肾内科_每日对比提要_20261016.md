# 肾内科指南追踪 · 10月16日对比提要

## 主标题：中国 IgA 肾病创新药"爆发日"——AP308（First-in-class IgA 蛋白酶）FDA IND 获批 + 泰它西普 / 伊普可泮双双登 NEJM

> **比对基线**：2026-10-15【当前版】| **来源等级**：⭐⭐⭐ 监管批准+顶刊（⚠️解读）

10月16日肾内科**无国内新指南发布**，但**中国 IgA 肾病创新药集中爆发**：**AP308（IgA 蛋白酶）FDA IND 今日获批**；**泰它西普、伊普可泮两项 Ⅲ 期双双登上《新英格兰医学杂志》（NEJM）**。

---

## 一、⭐ AP308 / PKU308（IgA 蛋白酶）——FDA IND 今日获批

| 项 | 内容 |
|------|------|
| ⭐ 进展 | 北京大学第一医院**吕继成 / 张宏**团队与礼邦医药联合开发，**10/16 新药临床（IND）获美国 FDA 批准**，即将进入首次人体临床 |
| ⭐ 机制 | **First-in-class IgA 蛋白酶**：**直接切割并清除已沉积于肾小球的致病性 IgA 及 IgA 免疫复合物** |
| 定位 | 与传统"上游减少致病 IgA 生成"路径互补——作用在**下游沉积环节** |
| 国内 | 9/28 "注射用 AP308" 已获 CDE 受理（受理号 CXSL2601066）|
| 意义 | ⭐ 全球从"减少生成"延伸到"**清除沉积**"的新机制；礼邦医药为**港股首家纯肾病赛道 18A 创新药企** |

## 二、⭐ 泰它西普登顶 NEJM：蛋白尿下降 55%

| 项 | 内容 |
|------|------|
| ⭐ 发表 | 2026/5 正式发表于 **NEJM**（北大一院**张宏 / 吕继成**团队牵头，全国 **72 家**研究中心）|
| ⭐ 疗效 | 39 周 24h UPCR 较基线降 **58.9%**，**安慰剂校正后降幅 55%**（刷新纪录）；UPCR<0.8 g/g 比例 **61.0% vs 19.5%**；**43% 完全缓解、79% 血尿转阴** |
| 机制 | **BLyS/APRIL 双靶点**（TACI-Fc 融合蛋白）——**从源头**减少致病性 IgA 生成 |
| 安全性 | 严重不良事件 **2.5% vs 安慰剂 8.2%**；以注射部位反应为主 |
| 监管 | 2026/6 获 **NMPA 附条件批准** IgA 适应证（**全球首个**双靶点生物制剂）|
| 待公布 | ⭐ **ASN 2026（10/22）** 将公布 **2 年结果**（开幕式全体会议口头报告）|

## 三、⭐ 伊普可泮（Fabhalta）APPLAUSE-IgAN 24 个月数据登 NEJM

| 项 | 内容 |
|------|------|
| ⭐ 发表 | Ⅲ期 **APPLAUSE-IgAN 24 个月最终数据**登 **NEJM**，并在 **WCN 2026** 报告 |
| 机制 | **补体 B 因子抑制剂**（补体"替代途径"开关）——first-in-class，**目前已唯一获批用于 IgAN 的补体抑制剂** |
| 用法 | ⭐ **口服** 200 mg，每日两次（非注射）|
| 监管 | 2024 加速批准 → **2026/7 获 FDA 完全批准** |
