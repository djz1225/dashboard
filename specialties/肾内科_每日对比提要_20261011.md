# 肾内科指南追踪 · 10月11日对比提要

> **比对基线**：2026-10-10【当前版】| **来源等级**：⭐⭐⭐ 专家共识/行业报道（部分 ⚠️解读）

10月11日肾内科**无新指南发布**。本期从**流行病学**切入，看清 IgA 肾病在中国"有多重"，以及**对因治疗的定位**。

## 一、⭐ IgA 肾病在中国的"分量"（《IgA 肾病临床实践 60 问(2026版)》）

| 指标 | 数据 |
|------|------|
| ⭐ **占肾活检比例** | 约 **54%**（我国最常见的原发性肾小球疾病）|
| ⭐ **患者规模** | 全国约 **500 万** 患者；每年新增确诊 **>12 万** |
| **好发人群** | **青壮年**，早期症状隐匿 |
| ⭐ **进展风险** | 约 **20%–40%** 患者**发病 20 年内**进展至终末期肾病（ESKD）|

> 政策背景：我国已将肾脏病纳入慢病防控体系（继心血管病、糖尿病、高血压之后）。

## 二、⭐ 耐赋康（布地奈德肠溶胶囊）：确立"对因治疗核心地位"

| 维度 | 要点 |
|------|------|
| ⭐ **作用环节** | 从 **"第 0 重打击"** 入手——靶向**肠道黏膜免疫**，从**源头减少 Gd-IgA1** 生成 |
| ⭐ **定位** | 全球首个**对因治疗**药物，共识明确其**核心药物**地位 |
| **价值** | **早期干预、争取最佳预后**；标志我国 IgAN 治疗迈入**源头靶向管理**新时代 |

## 三、⭐ IgA 肾病治疗"三层体系"（复习）

| 层级 | 内容 |
|------|------|
| **① 支持治疗** | **RASi（滴定至最大耐受）+ SGLT2i**（eGFR≥20 可用）；限盐、控压、戒烟、避 NSAIDs |
| ⭐ **② 对因/靶向** | **布地奈德肠溶胶囊**（肠道黏膜免疫）；新药陆续获批（atacicept / iptacopan 等，见 1008/1009）|
| **③ 免疫抑制** | 风险分层后激素/免疫抑制剂（如新月体>50% 时冲击联合）|
| **目标** | 尿蛋白 <0.5 g/d（最佳<0.3）；eGFR 年降 <1；血压 ≤120/70 |
