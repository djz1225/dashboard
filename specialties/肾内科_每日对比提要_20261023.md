# 肾内科指南追踪 · 10月23日对比提要

## 主标题：两条 BAFF/APRIL headline 昨夜同时交卷，两年 eGFR 斜率双双落在 −0.6——IgAN 的「硬终点时代」从今天开始算

> **比对基线**：2026-10-22【当前版】| **来源等级**：⭐⭐⭐ ASN 官网/企业公告 + 同步 NEJM（ORIGIN 3 数值可核）+ ⭐⭐ 中文转述与会议报道（⚠️解读）

10月23日肾内科**无新指南发布**。昨夜北京时间 23:05 与 23:19，ORIGIN 3 最终疗效分析与 TELIGAN 两年最终结果先后在丹佛开幕式全体会议读出，**两份数据均已落地**：两者的 104 周年化 eGFR 斜率都停在 **−0.6 mL/min/1.73 m²/年**，对照臂分别是 −5.6 与 −5.7。这意味着 IgAN 的疗效叙事正式从「蛋白尿降了多少」切换到「斜率保住了多少」。本期按「先数值、再解读、后待确认」三层记录。

---

## 一、⭐⭐⭐ ORIGIN 3 最终分析：复合终点降 76%，两年零透析/移植/死亡

| 项 | 内容 |
|----|------|
| **药物/机制** | atacicept（TRUTAKNA，atacicept-vymj），BAFF/APRIL 双配体抑制剂，**150 mg 每周一次皮下** |
| **设计** | III 期、全球、随机、双盲、安慰剂对照；**n=428** 原发性 IgAN；虽经优化支持治疗仍有持续蛋白尿 |
| **基线** | eGFR 约 **65** mL/min/1.73 m²；蛋白尿 **2.2 g/d**；SGLT2i 使用率 **60%–65%** |
| **52 周 eGFR 变化** | **−0.1**（atacicept）vs **−5.7**（安慰剂），校正组间差异 **5.6** mL/min/1.73 m² |
| **104 周年化斜率** | **−0.6** vs **−5.7**（另有报道为 −5.6，⚠️以 NEJM 表格为准），改善约 **5.0** mL/min/1.73 m²/年 |
| **复合肾脏进展终点** | **11 vs 38** 事件；**HR 0.24（95% CI 0.12–0.48），P<0.0001**，相对风险下降 **76%** |
| **终末期事件** | 透析≥30 天/肾移植/死亡：**0 例** vs 安慰剂 **8 例** |
| **次级终点** | 蛋白尿、Gd-IgA1、血尿分级均显著改善；第 36 周 UPCR 主要终点达标 |
| **安全性** | 总体与安慰剂相当；**无机会性感染**，无具临床意义的低丙种球蛋白血症 |
| **监管路径** | 2026 年 7 月基于中期结果获 FDA **加速批准**；计划 **2026 Q4** 提交 sBLA，目标 **2027 年**转为完全批准 |
| **发表** | 会议报告 + **同步发表于 *NEJM***（⚠️会议摘要部分数据未经同行评议，正文以 NEJM 为准） |

> ⚠️ 解读：**FDA 同意把 GFR 终点从第 104 周前移到第 52 周**，这是本试验最容易被忽略的设计细节——它使「52 周 eGFR 差异 5.6」成为可直接支撑确证性结论的读数，而不是一个观察性斜率。另一处要留意：**0 vs 8 的终末期事件是绝对数，不是率**，428 例两年内事件稀少，不能据此推算需要治疗多少例（NNT），只能作为方向性证据。

## 二、⭐⭐⭐ TELIGAN 两年：中国 318 例，斜率 −0.6，ESKD 0 vs 5

| 项 | 内容 |
|----|------|
| **药物** | 泰它西普（telitacicept），BAFF/APRIL 双靶点融合蛋白 |
| **设计** | III 期 TELIGAN，**n=318** 高进展风险 IgAN，**全国 72 家中心**，目前规模最大的中国人群 IgAN III 期 |
| **报告** | 摘要号 **TH-OR111**，开幕式全体会议（高影响力临床试验环节），**吕继成**（北京大学第一医院），10/22 9:19 MDT = 北京 23:19 |
| **104 周年化 eGFR 斜率** | **−0.6** mL/min/1.73 m²/年；组间差异 **5.1**（安慰剂组约 −5.7） |
| **确认 30% eGFR 下降** | 风险降低 **89%** |
| **蛋白尿（B 阶段减频给药）** | UPCR 较安慰剂仍降低 **60.7%** |
| **ESKD 事件** | **0 例** vs 安慰剂 **5 例** |
| **机制指标** | **Gd-IgA1 在 III 期层面首次获得确证性降低** |
| **中期对照（39 周）** | UPCR 较基线降 **58.9%**，安慰剂校正 **55.0%**；第 4 周即显现 |
| **监管** | 2026 年 6 月 NMPA 附条件批准（有进展风险的原发性 IgAN 成人） |
| **披露状态** | **会议摘要，未经同行评议**；⚠️ 与 ORIGIN 3 不同，泰它西普两年数据**未见同步全文发表**，安全性与亚组细节待原文确认 |

> ⚠️ 解读：两条 headline 的斜率**都是 −0.6**，这个巧合本身没有统计学意义，但有临床意义——它把「IgAN 肾功能下降可以被压到接近生理水平（KDIGO 视 <1 mL/min/1.73 m²/年 为目标）」从个别试验的偶然变成了**可重复的类别效应**。差别在两处：① TELIGAN 是**纯中国人群、318 例**，外推性更好但规模小于 428 例的全球试验；② 泰它西普在 B 阶段为**减频给药**，仍保住 60.7% 的 UPCR 降幅，这对长期依从性是加分项（⚠️ 具体给药间隔以摘要为准）。

## 三、⭐⭐ 昨夜同一会场里的「非 headline」：三条值得入档

| 研究/方向 | 关键读数 | 为什么记 |
|-----------|----------|----------|
| **lorundrostat（醛固酮合成酶抑制剂）Launch-HTN CKD 亚组**（Mineralys，10/22 公告） | 大型关键 III 期；CKD 与非 CKD 患者**血压降幅相似**，CKD 1–3 期内部一致；CKD 人群**白蛋白尿较安慰剂降低 52%**，与既往 CKD 试验结果相互印证 | 把「降压药」做出了「肾脏保护读数」，是高血压-CKD 交叉领域今年最实质的一条 |
| **环硅酸锆钠（SZC）透析高钾 RCT**（ASN 10/22 新闻发布） | 血透伴高钾成人中，SZC **降低血清钾**，并改善**与饮食钾限制相关的生活质量** | 首个把「饮食自由」做成终点的钾结合剂研究，改变的是患者每天吃什么，不是化验单 |
| **果蔬 vs 口服碳酸氢钠 vs 常规治疗**（ASN 10/22 新闻发布） | **108 例** 3 期 CKD 合并代谢性酸中毒，三组各 36 例；产碱果蔬（膳食酸负荷减半）在结局上**优于碳酸氢钠** | 证据等级不高（样本小），但方向罕见地支持「食物优于药片」，值得在门诊谈话里引用（⚠️ 具体终点数值待摘要确认） |

> ⚠️ 解读：这三条的共同点是**都落在「已有疗法的再定位」而非新靶点**。lorundrostat 是 MRA 之后的醛固酮通路第二波；SZC 与果蔬研究则提醒，CKD 管理里被低估的变量常常是**饮食结构与钾负荷**，而不是又一支新药。真正的临床增量往往出现在这类「不 headline」的位置。

## 🔧 其他动态

- **移植与 AKI 侧线**：CareDx 在 ASN 发布 KOAR 数据——AlloSure Kidney（dd-cfDNA）升高者，在临界排斥或 TCMR 背景下**不良移植物结局风险接近 3 倍**；另有一项独立随机试验显示该监测可**显著减少移植肾活检**而结局相当。SeaStar 的 QUELIMMUNE SAVE 注册分析（儿童脓毒症相关 AKI）报告 **60 天、90 天及出院时生存率显著更高**，且无器械相关不良事件（⚠️ 均为企业公告口径）。
- **今日中国声音**：**HLX79（E-602）+ 利妥昔单抗**治疗膜性肾病入选 Featured High-Impact Clinical Trials，摘要号 **FR-OR102**，10/23 **11:00–11:15 MDT**（北京时间 10/24 01:00 前后）。这是本届中国团队的第二条高影响力报告，主题从 IgAN 转向膜性肾病，值得单独跟。
- **待观察**：**PIONEER 篮子试验中期**（atacicept，覆盖成人 IgAN 与原发性膜性肾病两队列）在 10/24，将回答「同一机制能否跨病种」。若膜性肾病队列也出现斜率保护，BAFF/APRIL 的适应证边界会被重新画。
- **记录纪律**：昨夜企业通稿的 headline 数字（−0.6 / 76% / 89%）已可入档，但**亚组、安全性表、IgG 下降幅度、停药后反弹**四项尚未公开；ORIGIN 3 应以 **NEJM 全文**为最终依据，TELIGAN 只能标「会议摘要，未经同行评议」。

## 总结（一句话记忆）

> **一句话浓缩**：ORIGIN 3 与 TELIGAN 昨夜同时把两年 eGFR 斜率压在 −0.6（对照 −5.6 / −5.7），复合终点降 76%（HR 0.24）、ESKD 0 vs 5 与 0 vs 8——IgAN 从此按斜率排位，蛋白尿降幅只是入场券。
