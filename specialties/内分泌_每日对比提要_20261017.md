## 一、⭐⭐ UBT251（GLP-1/GIP/GCG 三靶点）2 期登《Cell Metabolism》

| 项 | 内容 |
|------|------|
| ⭐ 发表 | 2026/10/7，**《Cell Metabolism》**（中南大学湘雅二医院**周智广**团队 + 联邦制药，联合十余家医院） |
| ⭐ 机制 | **GLP-1 / GIP / GCG 三重受体激动剂**，化学合成，**每周皮下注射 1 次** |
| 设计 | 多中心、随机、双盲、安慰剂对照 **2 期**；**205 例**超重/肥胖成人（女性 59.0%，18–61 岁，**无 T2D**），疗程 24 周 |
| 剂量组 | 2 mg / 4 mg（起始 0.5 mg 或 1 mg）/ 6 mg vs 安慰剂 |
| ⭐ 主要终点 | 体重 LS 均值变化 **-19.7% 至 -13.6%**；安慰剂 **-2.0%**；**与安慰剂调整差异 -17.7% 至 -11.5%** |
| 次要终点 | 显著改善**腰围、BMI** 及**心血管代谢指标**；安全性可接受 |
| 结论 | **支持开展 3 期临床研究** |

> 含义：国产三靶点减重药进入**国际顶刊视野**，减重幅度已达 20% 量级（与替尔泊肽、retatrutide 同一梯队讨论区间；跨药头对头数据尚无，**不可直接比较**）。

## 二、⭐ 埃诺格鲁肽 SLIMMER 完整数据（48 周，n=664）

| 指标 | 结果 |
|------|------|
| ⭐ 体重 | **2.4 mg 组平均降 15.4%** |
| ⭐ 腰围 | **减少 12.8 cm** |
| ⭐ 达标率 | **92.8%** 受试者减重 **≥5%** |
| 耐受性 | 轻中度一过性胃肠道反应为主；**48 周因胃肠道不良事件停药仅 0.6%** |
| 平台期 | 1.8 mg / 2.4 mg 组**48 周体重持续下降，未见明显平台期** |
| 机制 | **偏向型 GLP-1RA**：选择性激活 cAMP 通路，减少 β-抑制蛋白募集 |
| 装置 | 可调节剂量注射装置，覆盖起始 → 维持各阶段剂量需求 |

## 三、⭐⭐ SLIMMER-UP-SWITCH：埃诺格鲁肽 vs 司美格鲁肽（头对头）

| 项 | 内容 |
|------|------|
| ⭐ 数据来源 | 中期数据于 **ADA 2026 科学年会**正式公布 |
| ⭐ 时点 | 治疗 **20 周** |
| ⭐ 结果 | 埃诺格鲁肽 2.4 mg **-12.8%** vs 司美格鲁肽 2.4 mg **-9.5%**（**P<0.05**） |
| 意义 | ⭐ **国产偏向型 GLP-1 在同剂量、同疗程头对头比较中优于司美格鲁肽** |
| 注意 | 为**中期分析**，最终结论以完整研究终点为准（**待原文确认**） |

> 用药定位：EECOH-1 研究（中国 32 家中心）显示埃诺格鲁肽 0.6 mg / 1.2 mg 组 24 周 HbA1c 分别降 **1.96% / 2.43%**，1.2 mg 组 **HbA1c<7.0% 达标率 80.3%**；故其"降糖 + 减重"双适应症路径已成立（T2D 适应症见 1016）。

## 四、⚠️ 肌肉保护——incretin 时代的"减重质量"问题

| 项 | 内容 |
|------|------|
| 出处 | **J Diabetes Investig 2026;17(10):1658-1661**《Beyond weight loss: Preserving muscle health in the incretin era》 |
| ⭐ 核心 | incretin 类药物从 GLP-1RA → 替尔泊肽 → 多靶点激动剂，**减重越强，肌肉流失风险越需关注**，**老年 T2D 患者尤为突出** |
| 机制关切 | 减重中瘦体重（lean mass）占比、肌力与躯体功能下降，可能抵消部分代谢获益 |
| 应对（⚠️ 解读）| **足量蛋白摄入 + 抗阻训练 + 定期体成分（BIA/DXA）评估**；老年人群需更保守的减重速度 |

## 五、⚠️ 依从性真实世界数据（值得关注的"反向"发现）

- **来源**：Health Transformation Alliance（HTA）分析，**2026/10/13** 发布
- **样本**：**1,270 万**例使用 GLP-1 治疗的 T2D 患者
- ⭐ **结果**：血糖/体重**无改善**组仍有 **83%** 持续用药；**应答良好**组为 **94%**
- **应用场景**：雇主 2027 计划年度的 GLP-1 覆盖评审与 PBM 谈判依据
- ⚠️ **解读**："疗效不佳但仍在用药"提示**剂量滴定不足、依从性管理与随访缺位**，而非单纯药物无效；国内尚无对应量级数据
