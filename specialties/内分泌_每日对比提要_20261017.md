## 一、⭐⭐ UBT251（GLP-1/GIP/GCG 三靶点）2 期登 Cell Metabolism

| 项 | 内容 |
|------|------|
| ⭐ 发表 | 2026/10/7，**《Cell Metabolism》**（中南大学湘雅二医院**周智广**团队 + 联邦制药，十余家医院）|
| ⭐ 机制 | **GLP-1 / GIP / GCG 三重受体激动剂**（化学合成），**每周皮下注射 1 次** |
| 设计 | 多中心、随机、双盲、安慰剂对照 2 期；**205 名**超重/肥胖成人（女性 59.0%，18–61 岁，**无 T2D**），24 周 |
| ⭐ 结果 | 体重 LS 均值变化 **-19.7% 至 -13.6%**；安慰剂 **-2.0%**；**与安慰剂调整差异 -17.7% 至 -11.5%** |
| 次要终点 | 显著改善**腰围、BMI** 及心血管代谢指标；安全性可接受 |
| 结论 | **支持开展 3 期临床** |

> 含义：国产三靶点减重药进入**国际顶刊视野**，减重幅度已接近/达到 20% 量级。

## 二、⭐ 埃诺格鲁肽 SLIMMER 完整数据（48 周）

| 指标 | 结果 |
|------|------|
| ⭐ 体重 | **2.4mg 组平均降 15.4%** |
| ⭐ 腰围 | **减少 12.8 cm** |
| ⭐ 达标率 | **92.8%** 受试者减重 **≥5%** |
| 耐受性 | 轻中度一过性胃肠道反应为主；**48 周因胃肠道不良事件停药仅 0.6%** |
| 平台期 | 1.8mg / 2.4mg 组 **48 周持续下降，未见明显平台期** |

## 三、⭐⭐ SLIMMER-UP-SWITCH：埃诺格鲁肽 vs 司美格鲁肽（头对头）

| 项 | 内容 |
|------|------|
| ⭐ 设计 | 中期数据于 **ADA 2026 科学年会**公布；**20 周** |
| ⭐ 结果 | 埃诺格鲁肽 2.4mg **-12.8%** vs 司美格鲁肽 2.4mg **-9.5%**（**P<0.05**）|
| 意义 | ⭐ **国产偏向型 GLP-1 在头对头比较中优于司美格鲁肽**（同剂量、同疗程）|

> 注：偏向型机制（选择性 cAMP 激活、减少 β-抑制蛋白募集）可能是疗效/耐受性优势来源。
