# 心血管指南追踪 · 11月3日对比提要

## 主标题：降脂的第一道门槛正在从"能不能达标"变成"愿不愿意打针"——首个每日一次口服 PCSK9 抑制剂把 74.9% 的极高危患者送进了 LDL-C<55 mg/dL

> **比对基线**：2026-11-02【当前版】| **来源等级**：⭐⭐⭐ 美国 FDA 批准公告（默沙东新闻稿，2026-07-16，可核）与国际会议（ASN Kidney Week 2026）正式报告数据 | ⭐⭐ 专业媒体（医学界肾病频道 10-26 稿、Radcliffe Cardiology AHA 日程解读）——⚠️ 解读来源，具体数值已与摘要数据交叉比对

11月3日心血管**无新指南发布**，AHA（美国心脏协会）2026 年会尚在会前第 3 天（11-06 开幕，芝加哥），当日亦无大型结局试验读出。本期的真正增量不在"新数据"，而在**一件已经发生但尚未进入心血管日常处方的事实**：2026-07-16，**enlicitide**（商品名 **LIPFENDRA**，每日一次口服大环肽类 **PCSK9**（前蛋白转化酶枯草溶菌素 9）抑制剂）获 FDA 批准用于成人高胆固醇血症（含 **HeFH**（杂合子家族性高胆固醇血症））的 LDL-C（低密度脂蛋白胆固醇）降低，成为**全球首个且唯一获批的每日一次口服 PCSK9 抑制剂**。它把 2026 血脂指南里那条"极高危 LDL-C<55 mg/dL"从"理论目标"变成了"口服可及"。

---

## 一、⭐⭐⭐ 口服 PCSK9 抑制剂落地：CORALreef 两项 Ⅲ 期的疗效底数

| 项 | 内容 |
|----|------|
| **药物与机制** | **enlicitide decanoate**（LIPFENDRA），口服大环肽，直接结合 PCSK9、阻断其与肝细胞 LDLR（低密度脂蛋白受体）结合，增加可清除循环 LDL-C 的受体数量；机制与已上市注射用 PCSK9 单抗相同，**无需注射** |
| **给药方案** | **20 mg 每日一次**口服片剂，可固定时间服用；两项 Ⅲ 期均治疗至 **52 周**，主要终点为 **24 周** LDL-C 较基线平均百分比变化 |
| **监管节点** | **2026-07-16 FDA 批准**（饮食与运动辅助，成人高胆固醇血症含 HeFH）；此前 2025-06-09 公布两项 Ⅲ 期顶线阳性 |
| **CORALreef Lipids** | n=**2904**（enlicitide 1935 / 安慰剂 969），有 ASCVD（动脉粥样硬化性心血管疾病）事件史或首发高危；**24 周安慰剂校正 LDL-C 降 56%**（95%CI −61~−51，P<0.001），单组较基线 **−57%**（安慰剂组 **+3%**）；non-HDL-C **−54%**、ApoB（载脂蛋白 B）**−50%** |
| **CORALreef HeFH** | n=**303**（202 / 101）；24 周安慰剂校正 LDL-C **降 59%**（95%CI −66~−53，P<0.001），单组较基线 **−58%**（安慰剂 **+3%**）；non-HDL-C **−52%**、ApoB **−48%** |
| **HeFH 特有不良反应** | 发生率高于安慰剂者为**腹泻 7% vs 2%**、**头晕 9% vs 4%**；两组因不良反应停药比例相近；Lipids 研究中两组不良反应频率与停药率亦相当 |
| **尚无的证据** | **CKD 人群的长期心血管结局**、以及总体**心血管结局试验（CVOT）**未读出——⚠️ 现有数据是"替代终点达标"，不是"事件下降" |

> ⚠️ 解读：这张表最该被记住的不是 56% 或 59%，而是**它解释了 2026 血脂指南为什么敢把非他汀药物的门槛往下压**。指南把 **PREVENT**（Predicting Risk of EVENTs）方程替代 PCE（汇总队列方程）、恢复 LDL-C 与 non-HDL-C 绝对靶目标、并把 **CAC**（冠状动脉钙化评分）、**Lp(a)**（脂蛋白(a)）、ApoB 深度纳入决策——这一整套"更早、更低、更持久"的逻辑，前提是**患者愿意长期用药**。而他汀不耐受、拒绝注射、依从性差这三类人，恰恰是过去 LDL-C 达标率上不去的真实原因。口服剂型拆掉的是"给药方式"这道墙，不是"疗效"这道墙。但必须把话说清楚：**替代终点达标率高不等于事件减少**，在 CVOT 读出前，enlicitide 的正确位置是"让该达标的人达标"，而不是"预防新药"。

### 1.1 由此推出的处方排序（本期新增的实操逻辑）

1. **第一层（不变）**：所有 ASCVD 患者先上**高强度他汀**（阿托伐他汀 40–80 mg 或瑞舒伐他汀 20–40 mg），4–12 周复查血脂四项＋肝功能。
2. **第二层（不变）**：他汀后未达 LDL-C<55 mg/dL（极高危）者，**首选加依折麦布 10 mg qd**——成本最低、口服、无需注射。
3. **第三层（本期变化）**：依折麦布后仍不达标，或**明确他汀不耐受**（肌痛＋CK 升高、或两次不同他汀失败）、或**拒绝一切注射**者，才有理由把"口服 PCSK9 抑制剂"与"注射用 PCSK9 单抗/英克司兰"并列讨论。
4. **第四层（不变）**：**Lp(a)≥125 nmol/L（50 mg/dL）** 者，风险约增 **1.4 倍**；**≥250 nmol/L（100 mg/dL）** 时风险接近翻倍——这类人应更严格压 LDL-C 并做**家族级联筛查**，而非等待 Lp(a) 靶向药。
5. **监测**：启用任何非他汀降脂药后 **4–12 周**复查血脂；达标后每 **6–12 个月**一次；同时记录 ApoB（他汀后 ApoB 与 LDL-C 不一致者优先看 ApoB）。
6. **禁忌/慎用提示**：妊娠期不推荐（⚠️ 具体分级待说明书）；严重肝功能不全、活动性肝病者不用；CKD 患者**无需按 eGFR 调整**现有 PCSK9 通路药物（详见肾内科同期数据）。

## 二、⭐⭐ AHA 2026 会前第 3 天：11-09 那场"心血管代谢风险新前沿"里藏着一个新靶点

| 项 | 内容 |
|----|------|
| **会议锚点** | AHA Scientific Sessions 2026，**2026-11-06 至 11-09**，芝加哥 McCormick Place；11-03 为会前第 3 天，无数据读出 |
| **11-09 08:00–09:15 CT 专场** | "New Frontiers in Cardiometabolic Risk Reduction"（心血管代谢风险降低新前沿），涉及四条互不相同的路径 |
| **路径一：新脂质靶点** | **TYDAL-TIMI 78**——**ANGPTL4**（血管生成素样蛋白 4）抑制。ANGPTL4 抑制 LPL（脂蛋白脂肪酶）活性，抑制后可降低甘油三酯；这是继 LDL-C、Lp(a) 之后第三条被单独设场的脂质通路 |
| **路径二：基因编辑** | **CRISPR-Cas9** 体内基因编辑（心血管代谢方向），属"一次给药、长期沉默"的单次治疗范式 |
| **路径三：剂型迁移** | **口服 GLP-1**（胰高血糖素样肽-1 受体激动剂）用于**OSA**（阻塞性睡眠呼吸暂停）及肥胖人群心血管结局——与本期口服 PCSK9i 是同一条"口服替代注射"主线 |
| **会前已知的反向信号** | LBS.02（11-08）仍按原定排期：**OCEANIC-STROKE** 的 **asundexian**（FXIa 抑制剂）风险分层分析、**REDUCE**（卒中后螺内酯为基础降压）、**OPTIMAL-Stroke**（卒中后强化降压）——三题均为"抗栓 vs 控压"的路线之争 |
| **与会期重叠提示** | 六场 LBS 的完整场次与题目已在 **11-02 期**逐场拆解，本期不重复 |

> ⚠️ 解读：把 ANGPTL4 和 CRISPR 放进"心血管代谢"同一专场，说明 AHA 对残余风险的判断又推进了一步——**LDL-C 之后是 Lp(a)，Lp(a) 之后是甘油三酯残余颗粒（ANGPTL4 通路）**。而 ZEUS（ziltivekimab，抗 IL-6 配体）与 Lp(a) HORIZON（pelacarsen）在 11-07 开场同台，等于官方承认"炎症"与"脂蛋白(a)"是两条平行解释。**三条通路（炎症、Lp(a)、TG 残余）＋两种给药革命（口服小分子、单次基因编辑）**，构成本届 AHA 的真实骨架。给临床的提醒只有一个：**这些都不是近期可处方的**，2026 年内能落地的仍是他汀＋依折麦布＋（口服或注射）PCSK9i 的组合。

## 🔧 其他动态

- **口服司美格鲁肽的心衰信号**：SOUL 试验二次分析（⚠️ 二级来源，期刊页码与在线日期待原文确认）显示，T2DM（2 型糖尿病）合并心衰患者中，口服司美格鲁肽使心衰复合结局风险**降 22%**，其中 **HFpEF**（射血分数保留的心力衰竭）亚组**降 41%**；严重不良事件比例低于安慰剂，获益不受是否联用 SGLT2i（钠-葡萄糖协同转运蛋白 2 抑制剂）影响。
- **心衰定义口径未变**：AHA/ACC/ESC/WHF 等联合发布的**心衰通用定义第二版（2026）**维持四分类框架，本期无更新。
- **临床落地提醒**：enlicitide 的**中国可及性与定价未知**，国内目前仍以他汀＋依折麦布＋注射用 PCSK9 单抗/英克司兰为主；如患者为"他汀不耐受且拒绝注射"，可在知情沟通后关注口服剂型上市节奏，**不作为现行推荐**。

## 总结（一句话记忆）

> **一句话浓缩**
> **口服 PCSK9 抑制剂 enlicitide 把极高危达标率做到 74.9%（LDL-C<55 mg/dL）、安慰剂校正降幅 56%–59%，但 CVOT 未读出；AHA 2026 会前第 3 天，真正的风向是 ANGPTL4 与 CRISPR 被收进"心血管代谢"专场——降脂的下半场在"换靶点"和"换给药方式"两条线上同时开跑。**
