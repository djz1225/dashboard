## 一、⭐ 并发症与合并症用药（CKD 2026）

| 领域 | 推荐 |
|------|------|
| ⭐ **心血管** | 口服**低剂量阿司匹林**预防缺血性心脏病事件（**1c**）；**CKD 1–4 期合并房颤优先 DOAC**（1c）|
| ⭐ **调脂** | **≥50 岁且 eGFR<60** → 他汀 ± 依折麦布（**1a**）；甘油三酯 ≥2.3 mmol/L 可用 **ω-3** 类 |
| **CKD-MBD** | 推荐**非含钙磷结合剂**（司维拉姆、碳酸镧、蔗糖羟基氧化铁）；**替那帕诺**为新型磷吸收抑制剂 |
| **继发性甲旁亢（SHPT）** | 活性维生素 D 及其类似物、拟钙剂；新一代**依特卡肽、伏依卡塞**提升达标率 |
| ⭐ **高钾血症** | **个体化长期管理**；口服降钾剂（**环硅酸锆钠、帕替罗默**）；急性升高用静脉钙剂 + 胰岛素/葡萄糖 |
| **酸中毒** | 血 **HCO₃⁻<22 mmol/L** → 口服**碳酸氢钠** |

## 二、⭐ 筛查与监测细节更新（CKD 2026）

| 要点 | 内容 |
|------|------|
| **定义** | CKD＝肾脏结构/功能异常**持续 >3 个月且影响健康**；**"持续性血尿"单列为诊断指标** |
| ⭐ **特殊人群估算** | 联合**血肌酐 + 胱抑素 C**：极限运动/健美、膝上截肢或截瘫、**BMI>40**、吸烟、特殊饮食等 |
| **实测 GFR** | 营养不良/肿瘤/心衰/肝硬化/消耗性疾病/用类固醇或影响肌酐分泌药物者 → 可测 **mGFR** |
| ⭐ **尿蛋白"假性"升高** | 避开**血尿、月经期、运动、感染**后复测，避免误诊 |
| ⭐ **监测频率** | eGFR≥60 但**尿蛋白未达标**者 → 提升至**每年 3 次** |
| ⭐ **低蛋白饮食** | CKD **3–5 期**蛋白质 **0.8 g/kg/天**（**既往 0.6–0.8**，本次上调）|
| **生活方式** | 中等强度活动每周≥5 次×30 分钟；**BMI 18.5–24.0**；戒烟 **+ 新增"限酒"** |
| **风险预测** | **KFRE**：5 年风险 3–5% 转诊；2 年 >10% 多学科；2 年 >40% 准备替代治疗 |

## 三、⭐ ERA（内皮素受体拮抗剂）成"第四联"

- 指南在"肾三联（RASi + SGLT2i + nsMRA）"基础上**新增第四大类**：
  - ⭐ **司帕生坦**：优先推荐用于**高危进展的 IgA 肾病**
  - ⭐ **阿曲生坦**：适用范围更广（IgA 肾病 + T2D 合并 CKD）
- 适用：**eGFR≥30** 且**足量 RASi 后仍持续蛋白尿**者

> **CKD 2026 补全：并发症用药——心血管（低剂量阿司匹林 1c、CKD1-4 期房颤优先 DOAC）、调脂（≥50 岁且 eGFR<60 他汀±依折麦布 1a）、CKD-MBD（非含钙磷结合剂+替那帕诺）、SHPT（依特卡肽/伏依卡塞）、高钾（环硅酸锆钠/帕替罗默）、酸中毒（HCO₃<22 补碱）；筛查细节——特殊人群加胱抑素C、警惕尿蛋白假性升高、尿蛋白未达标者每年查 3 次、低蛋白饮食上调至 0.8 g/kg/d、新增限酒；ERA（司帕生坦/阿曲生坦）成"第四联"。**
