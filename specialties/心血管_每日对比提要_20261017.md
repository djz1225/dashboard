## 一、⭐⭐《第五版心肌梗死通用定义》——心梗诊断的范式变革

| 项 | 内容 |
|------|------|
| ⭐ 场次 | GW-ICC TV 第一直播间（三层商务中心北侧）**10/17 11:00–11:30** |
| ⭐ 定位 | 官方表述为"**心梗诊断的范式变革与精准诊疗新时代**" |
| 背景 | 第五版全球定义于 **ESC 2026 年会期间发布**（2026 年），核心变化为**分型框架重构** |
| 关键变化（待原文确认）| 由 1–5 型数字分型 → **原发性 / 继发性 / 围术期相关**三类临床情境；强调**急性心肌损伤需结合缺血证据 + 影像确认** |
| 鉴别要点 | **肌钙蛋白升高 ≠ 心肌梗死**；需综合**动态变化趋势、症状、心电图、心脏/冠脉影像**判断 |
| 实践意义 | ⚠️ 直接影响**急诊胸痛判别**、**2 型（供需失衡性）心梗识别**、**围术期心梗判定** |
| 落地建议 | 危重症场景下尤需避免"唯肌钙蛋白论"；冠脉造影等侵入性检查必要性需审慎评估、多学科协作 |

> 优先级判断：这是**本周心血管最高优先级**内容。数字分型改为临床情境分型后，**病案首页/诊断编码、临床路径、质控口径**都需同步核对，建议第一时间查原文与会议回放。

**建议动作清单（⚠️ 解读，非指南原文）**
- 核对本院**急性心肌损伤 vs 心肌梗死**的判定路径是否写明"需缺血证据"；
- 复核**围术期**患者的诊断表述习惯；
- 关注**继发性（供需失衡）心肌损伤**在重症/围术期的误诊与漏诊风险；

## 二、⭐ 非奈利酮：从 HFrEF / T2D-CKD 走向 LVEF≥40% 心衰

| 项 | 内容 |
|------|------|
| ⭐ 场次 | GW-ICC TV **10/17 10:00–10:30**，"精准护心，循证护航" |
| ⭐ 主题 | **非奈利酮在 LVEF≥40% 心衰中的临床应用策略** |
| 药理 | **非甾体类盐皮质激素受体拮抗剂（nsMRA）**，强效抗纤维化/抗炎 |
| 意义 | nsMRA 的适用人群从"T2D 合并 CKD + HFrEF"向**HFmrEF / HFpEF（LVEF≥40%）**扩展 |
| 待确认 | 具体推荐人群、eGFR/血钾门槛与起始剂量策略——**待演讲原文确认** |

> 呼应 1013 / 1014：nsMRA 正从"肾病用药"变成**心-肾-代谢通用支柱**（与 RASi、SGLT2i、GLP-1RA 并列的"四类药"格局）。

## 三、⭐ HCM：从"缓解症状"到"靶向 + 全生命周期管理"

| 项 | 内容 |
|------|------|
| 专题会 | **10/17 08:30–12:00，309B**《HCM 心见：识"心"明鉴，精治致远》，马长生领衔 |
| Session 1 | 同为心肌肥厚，为何**疾病轨迹与结局迥异**？整合**临床 + 影像 + 遗传**做精准诊断与风险分层 |
| Session 2 | HCM 步入**靶向诊疗时代**：从"疾病治疗"→**全生命周期管理**；目标延伸至**心脏逆重构与长期结局** |
| ⭐ 关键药物 | **第二代心肌肌球蛋白抑制剂（CMI）**：直接作用于心肌肌球蛋白、抑制过度收缩；**Ⅲ期 24 周使 LVOT 压差降低 50 mmHg**，**用药 2 周即可上调剂量**（2025/12 于中国获批） |
| 传统手段局限 | 传统药物仅缓解症状、无法干预病因；侵入性治疗（室间隔减容）技术要求高、可及性有限 |

> 趋势：HCM 的疗效评价正从"症状改善"转向**压差 + 重构 + 长期结局**三级终点。

## 四、⭐ 心血管诊疗创新论坛：心肌病 × 血脂"两条通路的靶向对话"

| 项 | 内容 |
|------|------|
| 时间 | **10/17 08:30 启幕**，全程约 3.5 小时 |
| 结构设计 | 把**肥厚型心肌病（HCM）**与**甘油三酯代谢异常**纳入同一议程——两条通路、同一种"从对症到靶向"的转向 |
| ⭐ 通路 A | **第二代 CMI**（心肌收缩通路）：Ⅲ期 24 周 LVOT 压差降 50 mmHg |
| ⭐ 通路 B | **靶向 APOC3 的小干扰 RNA（siRNA）**——全球首个，从源头沉默 APOC3，显著降低**甘油三酯**及**急性胰腺炎**风险（2026/1 于中国获批） |
| 疾病背景 | 家族性乳糜微粒血症综合征 / 重度高甘油三酯血症患者长期面临**急性胰腺炎反复发作**，疾病负担沉重 |
| 共同提问 | 当传统手段只能在"症状与指标"层面做减法，**精准干预致病机制**的窗口是否已打开 |
