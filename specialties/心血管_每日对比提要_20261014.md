## 二、⭐ ESC 2026 定调：糖尿病 = 心衰"A 期"，5 类药物可预防

| 项 | 内容 |
|------|------|
| ⭐ 定位 | 2026 ESC 心衰指南将**糖尿病患者定义为心衰"A 期（风险期）"**，与《中国心衰指南 2024》理念一致 |
| ⭐ 筛查 | 糖尿病者建议**每年查 BNP / NT-proBNP + 心脏彩超** |
| ⭐ 5 类预防药 | **①ACEI/ARB ②沙库巴曲缬沙坦 ③SGLT2i ④非奈利酮（T2D 合并 CKD）⑤（代谢类，如二甲双胍）** —— 按合并症**个体化选择，非人人全用** |

> 呼应 1013"Stage B 黄金窗口"：**A 期（有危险因素）→ B 期（结构/标志物异常）→ C 期**，是一条连续防治链条。

## 三、⚠️ 两项顶刊研究速览（心血管风险新证据）

| 研究 | 要点 |
|------|------|
| **夜间光照（EUR HEART J）** | 夜间光照**时间越长、强度越高**，心脏越易**变厚、变僵**；心衰 / 房颤 / 心梗 / 卒中 / 心血管死亡风险**同步升高** —— 睡眠环境亦是干预点 |
| **食品防腐剂（EUR HEART J）** | 11 万人队列：多种常用防腐剂与**高血压 / 心血管 / 脑血管 / 冠心病**风险升高相关，部分效应经**高血压与 T2DM 介导** |

## 四、血脂管理（延续）——ApoB 与 LDL-C 新定位

| 项 | 内容 |
|------|------|
| 2026 ACC/AHA 血脂指南 | LDL-C 致动脉粥样硬化作用**不只由数值决定**，还受颗粒数、大小、**ApoB 匹配度**、炎症影响 |
| 实践 | 达标后测 **ApoB** 可指导进一步干预；未降脂者测 ApoB 提升风险评估精度；**成年人均应筛查 Lp(a)** |
