# 内分泌指南追踪 · 10月29日对比提要

## 主标题：口服小分子 GLP-1 首次在 T2DM 拿到阳性 II 期顶线，同期国产超长效胰岛素开出首批处方——竞争点正式从"靶点"落到"少打针"

> **比对基线**：2026-10-28【当前版】| **来源等级**：⭐⭐⭐ 港交所公告与药企官方披露（试验编号、样本量、给药方案可核）+ ⭐⭐ 专业媒体与会议报道（⚠️解读）

10月29日内分泌**无新指南发布**。本期是"给药方式"的一天：歌礼制药 **10/29** 在港交所公告，口服小分子 **GLP-1R（胰高血糖素样肽-1 受体）** 激动剂 **ASC30** 片治疗 **T2DM（2 型糖尿病）** 的美国 II 期研究取得**积极顶线结果**；三天前（**10/26**）恒瑞 **舒地胰岛素（瑞恒盈）** 在国内开出首批处方，成为中国首款自研长效胰岛素类似物。两件事一南一北，说的却是同一句话——**疗效故事已经讲完，接下来比谁能把针减掉、把货供上**。

---

## 一、⭐⭐⭐ ASC30：口服小分子 GLP-1 在 T2DM 拿到第一个阳性 II 期顶线

| 项 | 内容 |
|----|------|
| **药物** | **ASC30**，口服**小分子** GLP-1R 激动剂，**每日一次**口服片剂 |
| **公告时间** | **2026-10-29**，歌礼制药于港交所公告"积极顶线结果" |
| **研究** | 美国 II 期研究，注册号 **NCT07321678** |
| **设计** | **13 周**、**100 例** T2DM 受试者，评估疗效、安全性与耐受性 |
| **主要终点** | 第 **12 周**（具体指标与降幅数值**待原文确认**） |
| **结果方向** | 公司口径为"**积极顶线结果**"；具体 HbA1c（糖化血红蛋白）降幅、安慰剂/阳性对照差值、胃肠道不良事件率**尚未在公告摘要中给出可核数字** |
| **同类参照** | 2026 年已发表的 GLP-1/GCGR（胰高血糖素受体）双激动剂类特异性 **meta 分析**纳入 **19 项 RCT**（Diabetes, Obesity and Metabolism, 2026），提示该双靶类可有意义的减重与代谢改善 |

> ⚠️ 解读：ASC30 真正的分量不在"又一个 GLP-1"，而在**"小分子 + 口服 + 每日一次"**这三个词同时成立。多肽类 GLP-1 的产能瓶颈来自发酵与冷链，小分子路线一旦走通，**成本结构与供应弹性会被重写**——这也是国产厂商最现实的差异化位置。但必须把三点分开看：第一，**II 期顶线 ≠ III 期终点**，13 周、100 例的样本量足以看趋势，不足以定疗效边界，减重与降糖的剂量-反应关系也尚不清晰；第二，**公告未披露具体降幅**，在数值公开前不宜与司美格鲁肽、埃诺格鲁肽做任何横向比较；第三，"积极"的口径由申办方定义，**主要终点是否达到预设统计学显著、以及是否含阳性对照，待原文确认**。

**待补的三件事（⚠️ 属梳理，非公告内容）**

- **对照设置**：II 期为安慰剂对照还是活性对照，直接决定这个结果能否支撑 III 期的非劣效设计。
- **耐受性**：口服小分子的胃肠道反应谱与多肽类是否同构，是长期依从性的关键变量。
- **体重终点**：T2DM 人群中减重为次要终点还是探索性终点，决定其后续在肥胖适应证上的可延展性。

## 二、⭐⭐ 舒地胰岛素：国产长效胰岛素的"首批处方"，赢在夜间低血糖

| 项 | 内容 |
|----|------|
| **药物** | 舒地胰岛素（商品名**瑞恒盈**），恒瑞医药自研 **1 类**创新生物制品 |
| **定位** | **中国首个自主研发的长效胰岛素类似物**，用于成人 T2DM |
| **获批时间** | **2026-07-29** 获批；**2026-10-26** 首批患者治疗启动（获批后约两个月） |
| **作用时长** | **42 小时**平稳控糖（公司口径），强调夜间血糖覆盖 |
| **III 期结论** | 相较**甘精胰岛素 U100**：**等效降糖**，**夜间低血糖风险显著更低** |
| **落地医院** | 北京大学人民医院（纪立农团队）、复旦大学附属中山医院（李小英团队）、上海交通大学医学院附属新华医院（苏青团队） |
| **研发投入** | 公司披露研发周期**十余年**、投入**超 5 亿元** |

> ⚠️ 解读：基础胰岛素的国产替代讲了多年，真正的门槛从来不是"能不能做出来"，而是**长期稳定性、层析收率与供应一致性**——这也是公告里"十余年"这三个字的分量所在。临床上更值得记的是**终点选择**：III 期拿"夜间低血糖显著更低"作为差异点，而不是去拼 HbA1c 绝对值，这是基础胰岛素最诚实也最有用的比较维度。需要克制的地方是，"等效降糖"是**非劣效框架内的结论**，不能读成"一样好甚至更好"；而 42 小时的作用时长在**老年、肾功能不全、进食不规律**人群中的安全性数据，公开信息中尚未细化（⚠️待原文确认）。

**同期给药方式侧的两条旁证**

- **双胰岛素**：东阳光药**德谷门冬双胰岛素**于 **2026-10-08** 获国家药监局批准，用于 T2DM，一次覆盖基础与餐后。
- **复方制剂**：诺和诺德**依柯胰岛素司美格鲁肽注射液**于 **2026-10-15** 在国内获批新适应症（血糖控制不佳的成人 T2DM，联合口服降糖药）——把"基础胰岛素 + GLP-1"压进一支笔。

## 🔧 其他动态

- **甲状腺眼病**：罗氏 **satralizumab（Enspryng）** 于 **2026-10-16** 获 FDA 批准用于成人 **TED（甲状腺相关眼病）**，为首个可**居家皮下给药**的治疗选择；依据 III 期 **SatraGO-1 / SatraGO-2**，无论活动期与病程长短均可改善眼球突出与复视（10/26 起国内媒体广泛转载）。该药此前已在约 90 个国家获批用于 **NMOSD（视神经脊髓炎谱系疾病）**，安全性基础较厚。
- **糖胖负担口径**：CEAAC2026（中国医师协会内分泌代谢科医师年会）会议资料给出我国成人糖尿病患者约 **1.48 亿**、超重/肥胖成人总患病率 **57%**——这组数字是判断减重药市场容量的基准，但属会议引用口径（⚠️来源为会议报道，非流调原文）。
- **骨质疏松侧线**：京医论坛（10/25）提及兼具促骨形成与抑制骨吸收双重作用的**罗莫索珠单抗**已在国内获批；同时强调减重过程中的"**骨肌同管**"，以及磁共振特殊序列可早于双能 X 线识别骨质量改变（⚠️为专家观点，非指南推荐）。
- **待观察**：口服小分子 GLP-1 若在 III 期成立，"口服 vs 皮下"的定价与医保准入路径将成为比疗效更硬的变量；目前国内尚无同类口服小分子 GLP-1 获批用于 T2DM 的公开信息（⚠️属推演，待核）。

## 总结（一句话记忆）

> **一句话浓缩**：ASC30 用"**口服 + 每日一次 + 100 例 13 周 II 期顶线积极**"把 GLP-1 从注射推向口服，舒地胰岛素用"**42 小时 + 夜间低血糖更低**"把国产基础胰岛素送进首批处方——**2026 年的内分泌竞争，不在分子多新，而在给药方式能不能被患者长期坚持、被工厂长期供上。**
