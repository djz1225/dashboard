# 肾内科指南追踪 · 10月13日对比提要

## 一、⭐ ASN Kidney Week 2026 前瞻：焦点在"实施"

| 维度 | 内容 |
|------|------|
| ⭐ **四大药理支柱** | **RAS 抑制（RASi）、GLP-1 受体激动剂、nsMRA、SGLT2 抑制剂** |
| ⭐ **会议焦点** | **"怎么用"**——**治疗顺序（sequencing）、联合策略（combination）、向晚期 CKD 与透析人群的扩展** |
| **IgA 肾病** | 新药（BAFF/APRIL、补体等）继续是热点 |
| **其他** | 现有药物在**常规照护中更广泛、更安全应用**的试验数据 |

> 含义：CKD 治疗已从"有没有药"进入**"怎么组合、何时用、用到多晚"**的精细化阶段。

## 二、⭐ INFINITY 研究（《柳叶刀》）：非奈利酮"广泛 CKD"心肾获益

| 项目 | 内容 |
|------|------|
| ⭐ **设计** | **汇总分析**：FIDELIO-DKD + FIGARO-DKD + **FIND-CKD** |
| **规模** | **14,574 例**，覆盖**糖尿病及非糖尿病** CKD 广泛病因人群；中位随访 **>3.1 年** |
| ⭐ **结果** | 与安慰剂相比，非奈利酮在**广泛 CKD 患者**中显示**心肾获益**（减缓 eGFR 下降、降低复合终点）|
| **意义** | 为**非奈利酮从"T2D-CKD"扩展到"非糖尿病 CKD"**提供汇总级证据（呼应 1004/1010）|

## 三、⭐ CKD 2026 指南：蛋白尿控制目标

| 人群 | 目标 |
|------|------|
| ⭐ **早中期糖尿病肾病** | **UACR < 30 mg/g** |
| ⭐ **非糖尿病肾病** | **UPCR（尿蛋白/肌酐比）< 300 mg/g** |

## 四、⚠️ IgA 肾病用药的"特殊情形"（《60 问 2026》）

| 情形 | 处理要点 |
|------|----------|
| **HBV / HCV 感染** | HBV 参考全身糖皮质激素原则；HCV 阳性先 DAA 治疗 12 周；联用注意增加布地奈德暴露 |
| **肝功能损害** | 中度加强监测、倾向停用；**重度立即停用** |
| **腹泻** | **急性腹泻不建议启动**；慢性腹泻个体化调整空腹时间、可用解痉药 |
| **肥胖/糖尿病** | 用药前评估获益与代谢影响、筛查指标；用药中复查并制定降糖方案 |
| **儿童/妊娠/哺乳** | 儿童取决于医师获益判断；**妊娠期避免使用**；哺乳期不建议、必要时停止哺乳 |
| **肾移植后复发** | 可考虑使用 |
