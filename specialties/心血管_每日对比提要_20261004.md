# 心血管指南追踪 · 10月4日对比提要

## 一、⭐ 第五版心肌梗死全球统一定义（2026）

| 项目 | 内容 |
|------|------|
| **发布方** | ESC / ACC / AHA / WHF 联合工作组 |
| **发表** | **JACC 2026, 88(11): 1314–1368** |
| **沿革** | 前四版：2000 / 2007 / 2012 / 2018，本次为**第五版** |
| **要义（框架）** | 延续**5 型分类**；强化**高敏肌钙蛋白（hs-cTn）**动态变化为核心；影像（CMR/CT）与心电图辅助分型；强调与心肌损伤、心肌炎的鉴别 |
