## 一、⭐ ADA/EASD 2026《T2D 管理共识报告》

| 维度 | 关键更新 |
|------|----------|
| **范式迁移** | 从"管理高血糖" → **"整体管理 T2D 及其共病多重长期疾病"** |
| ⭐ **二甲双胍不再"首选"** | SGLT2i 和/或 GLP-1 类（含双激动剂）的**器官保护证据独立于二甲双胍**，**多数患者可从诊断时早期引入** |
| ⭐ **联合治疗前移** | 合并 **CVD / CKD / HF** 者应考虑 **SGLT2i + GLP-1 类早期联合**，**无论 HbA1c 如何** |
| ⭐ **非奈利酮入局** | 首个进入该共识路径的**非降糖药物**：用于**白蛋白尿性 CKD**（UACR≥3.0 mg/mmol、eGFR≥25）及 **HFpEF / HFmrEF** |
| **生活方式"处方化"** | 针对 **"5S"**（站立、步行、出汗、力量、睡眠）给出量化目标与处方模板 |
| **胰岛素规则重写** | 仅以基础胰岛素起始，**通常在 GLP-1 类之后**，并保留心肾保护药物；衰弱者减停磺脲类；难治者筛查高皮质醇血症 |
| **体重与血糖同等重要** | 减重 10% 追求缓解；**减重效力成为选药维度**；减重期强调**蛋白摄入 + 抗阻运动保肌**，达标后转维持 |

> ⭐ 国际联合共识（ADA + EASD）。另有**13 项证据空白**待填补。

## 二、⭐ EASD 2026"中国之声"：王卫庆团队重构 HbA1c 目标

- **研究一（LBA24）**：国家标准化代谢性疾病管理中心（MMC）**217,645 例** T2DM 前瞻队列（全国 35 中心，随访至 2026-03）——重新评估**最佳 HbA1c 目标**，分别分析 **MACE** 与 **ESRD** 终点，并考察**减重 5% 是否改变关联**
- **研究二**：基于 **ChinaMAP 遗传队列**，用**减重 + 遗传风险**重构 HbA1c 控制目标
