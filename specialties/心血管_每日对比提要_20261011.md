# 心血管指南追踪 · 10月11日对比提要

## 主标题：深析——CKM 与心衰"框架融合"：肥胖是心肾代谢的"起点"

> **比对基线**：2026-10-10【当前版】| **来源等级**：⭐⭐⭐ JACC 述评/指南（⚠️解读）

10月11日心血管**无新指南发布**。JACC 一篇述评提出：**2026 年的三部指南 + 心衰第二版通用定义正在"融合"成一个整体框架**，而**肥胖是这条链条的起点**。

---

## 一、⭐ JACC：CKM 与心衰的"框架融合"

| 要点 | 内容 |
|------|------|
| ⭐ **核心论点** | 2026 三部指南（血脂 / 高血压 / CKM）+ 心衰第二版通用定义，**正从"疾病治疗"走向"整体健康（Whole Health）"** |
| ⭐ **肥胖的位置** | **肥胖在 CKM 连续谱的"第 1 期"即入列**，可**先于**高血压、糖尿病、CKD、临床 CVD **多年**出现 |
| ⭐ **与 HFpEF 的关系** | HFpEF 是"集大成者"——常并存**内脏肥胖、胰岛素抵抗、系统性炎症、血浆容量扩张、高血压、CKD、骨骼肌功能障碍** |
| ⭐ **CKM 指南的干预** | 按**表型与严重度**分层：**生活方式 + 减重 + GLP-1 基础药物治疗 + 代谢/减重手术** |

> 含义：**心内科的"入口"要前移到肥胖/代谢**——肥胖不只是内分泌问题。

## 二、⭐ 心衰通用定义（第二版）要点回顾

- 不再把 **LVEF 固定数值**作为唯一分型标准 → **HFrEF / HFpEF / HFimpEF** 三型 + **动态病程**（改善/缓解/康复）
- **18 类**标准化病因分类；强调**多维综合评估**、警惕漏诊 HFpEF
- ⚠️ 提示：**不因指标一时改善而擅自停药**，尽早启动指南导向药物治疗
