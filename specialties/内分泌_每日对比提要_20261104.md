# 内分泌指南追踪 · 11月4日对比提要

## 主标题：国产口服小分子 GLP-1 走到「受理」这一步——52 周减重 12.2%、近三成减重≥15%，而注射阵营正把战场挪到「减重之后的心衰与心血管结局」

> **比对基线**：2026-11-03【当前版】| **来源等级**：⭐⭐⭐ 企业公告与监管受理通知书（华东医药 2026-11-02 受理、11-03 公告，受理号可核）＋ 药物临床试验登记与信息公示平台（安进 Ⅲ 期，CTR20264119）| ⭐⭐ 专业媒体与行业观察（证券时报、上海证券报、证券日报、药圈观察局 11-03/11-04 稿）——⚠️ 解读来源，数值已与公告交叉比对

11月4日内分泌·体重管理领域**无新指南发布**，也无大型 Ⅲ 期读出。本期增量来自一件**已经发生但被当成「公司新闻」而低估的事**：2026-11-02，**NMPA**（国家药品监督管理局，National Medical Products Administration）受理了华东医药自研的**卡维列隆氨丁三醇片**（研发代码 **HDM1002**，英文名 **conveglipron**，口服小分子 **GLP-1**（胰高血糖素样肽-1，glucagon-like peptide-1）受体完全激动剂）用于**成人长期体重控制**的上市许可申请，11-03 晚公告，11-04 各财经渠道集中见报。这是**第三款申报上市的国产口服小分子 GLP-1 减重药**。同日另一侧，**安进**（Amgen）的 **maridebart cafraglutide**（MariTide，AMG133）在中国登记 Ⅲ 期——它走的是「激动 GLP-1、**拮抗** GIP（葡萄糖依赖性促胰岛素多肽，glucose-dependent insulinotropic polypeptide）」的反向路线。一个在申请上市，一个刚起步，同一赛道的两端在这一天同时露头。

## 一、⭐⭐⭐ 卡维列隆（HDM1002）：国产口服小分子 GLP-1 的第三张「受理通知书」

| 项 | 内容 |
|----|------|
| **药物与机制** | 卡维列隆氨丁三醇片（conveglipron，HDM1002），化学药品 **1 类**，口服小分子 **GLP-1R**（GLP-1 受体）**完全激动剂**，每日一次；吸收**不受进食与饮水影响**，无需空腹条件、无需服药后等待时间 |
| **监管节点** | **2026-11-02** 收到 NMPA《受理通知书》（受理号 **CXHS2600143 / 144 / 145**），规格 **50 mg、100 mg、200 mg**；**2026-11-03** 晚公告；申请事项为境内生产药品注册上市许可 |
| **申报适应症** | 在控制饮食与增加体力活动基础上，成人长期体重控制：**BMI**（体质指数，body mass index）**≥28 kg/m²**（肥胖），或 **≥24 kg/m²**（超重）且伴至少一种体重相关合并症（高血压、血脂异常、高尿酸、糖代谢异常、脂肪肝、心血管疾病等） |
| **关键 Ⅲ 期** | **HDM1002-301**：多中心、随机、双盲、安慰剂对照、平行设计，**857 例**成人超重/肥胖，治疗 **52 周**；比较 200 mg qd、400 mg qd 与安慰剂；主要终点为 44 周体重较基线变化（⚠️ 具体分析口径以说明书/刊文为准） |
| **44 周疗效** | 200 mg 组 **−9.2%**、400 mg 组 **−10.7%**，安慰剂组 **−1.5%**；达全部主要终点与关键次要终点 |
| **52 周疗效** | 200 mg 组 **−10.7%**、400 mg 组 **−12.2%**；**未观察到减重平台期** |
| **达标率（52 周，400 mg 组）** | 减重 **≥5%：79.6%**；**≥10%：53.9%**；**≥15%：29.1%**（均显著高于安慰剂组） |
| **伴随获益（方向性）** | 腰围、空腹血糖、**HbA1c**（糖化血红蛋白，glycated hemoglobin）、血压、**hs-CRP**（超敏 C 反应蛋白，high-sensitivity C-reactive protein）及甘油三酯改善；肝酶指标显著下降（安慰剂组呈上升趋势）、肝脏脂肪含量大幅降低；减重以脂肪减少为主、内脏脂肪显著减少 |
| **安全性** | 总体特征与 GLP-1 受体激动剂类一致，以轻中度胃肠道反应为主，未观察到新的安全性信号，肝脏安全性良好 |
| **研发投入与后续** | 截至 **2026-09-30**，该项目（含体重管理与降糖两项适应症）研发直接投入约 **5.07 亿元**（未经审计）；**T2DM**（2 型糖尿病，type 2 diabetes mellitus）中国 Ⅲ 期推进中；中美双报，另在探索与 **SGLT2**（钠-葡萄糖协同转运蛋白 2，sodium-glucose cotransporter 2）抑制剂组成复方 |
| **竞争位次** | 国产已有 **3 款**口服小分子 GLP-1 申报上市（闻泰医药/箕星 **VCT220**、恒瑞 **HRS-7535** 在前）；全球已获批上市的口服小分子 GLP-1 仅 **orforglipron**（奥氟格列隆）一款 |

> ⚠️ 解读：这张表真正值得记的不是 12.2%，而是**「44 周达标、52 周继续下降、无平台期」**这一条时间曲线。GLP-1 类药物的减重曲线通常在 40–60 周进入平台，而 HDM1002 在 52 周仍在下降——这既可能是剂量仍在累积效应，也可能是 52 周还没到真正的平台，**不能据此推断「比司美格鲁肽强」**：跨试验比较没有意义（人群 BMI 分布、生活方式干预强度、安慰剂反应 −1.5% 与 −2.0% 都不同）。第二点更实际：**「不受进食饮水影响」是这个药相对口服司美格鲁肽（肽类，必须空腹、限水 30 分钟）的真实差异**，而不是「口服 vs 注射」的差异；对依从性的影响要落到「服药场景限制」上才成立。第三点，受理不等于批准：公告本身写明「审评审批时间、审批结果及未来市场竞争形势均存在诸多不确定性」，**中国目前仍无口服小分子 GLP-1 获批减重适应症**。

| 品种（企业） | 最新节点 | 减重数据口径 | 与本品的差异 |

## 二、⭐⭐ 安进 MariTide 在中国登记 Ⅲ 期：GLP-1 激动＋GIP 拮抗，反向设计的第一次中国落点

| 项 | 内容 |
|----|------|
| **药物** | **maridebart cafraglutide**（MariTide，AMG133），皮下注射 **GLP-1R 激动剂 / GIPR**（GIP 受体）**拮抗剂**，抗体-肽偶联结构，长效（⚠️ 给药间隔以方案为准） |
| **机制反差** | 与**替尔泊肽**（tirzepatide，GLP-1/GIP **双激动**）相反：安进选择「激动 GLP-1、**阻断** GIP」，即对 GIP 通路做减法 |
| **中国节点** | **2026-11-02** 在药物临床试验登记与信息公示平台登记 Ⅲ 期，登记号 **CTR20264119**；Ⅲ 期、随机、双盲、安慰剂对照、平行组 |
| **人群与规模** | 肥胖或超重（伴至少 1 种体重相关合并症）中国成人；**35 家**医疗机构，拟入组 **300 人** |
| **主要终点** | 治疗 **52 周**时体重较基线的变化百分比 |
| **已开的结局研究** | **MARITIME-HF**：**HFpEF**（射血分数保留的心力衰竭，heart failure with preserved ejection fraction）或 **HFmrEF**（射血分数轻度降低的心衰）合并肥胖，评估死亡与发病率；**MARITIME-CV**：**ASCVD**（动脉粥样硬化性心血管疾病，atherosclerotic cardiovascular disease）合并超重/肥胖，评估心血管结局 |
| **上市状态** | **尚未在任何国家获批**，未进医保；本次登记仅代表中国临床开发推进 |

> ⚠️ 解读：GIP 这条通路在 2026 年出现了真正的分歧——礼来用「双激动」把减重推到 20% 以上，安进用「拮抗」走另一条路。机制上并不矛盾：GIP 受体在**脂肪组织**与**中枢**的作用与在**胰岛 β 细胞**的促胰岛素作用并不一致，拮抗外周 GIP 信号可能改善**瘦体重保留**与**食欲抑制的持续性**（⚠️ 机制假设，待人体数据验证）。对中国临床更实际的两点：**第一，它的 Ⅲ 期主要终点只有 52 周体重变化，不含体成分**，所以「减脂不减肌」这类关键问题在这个试验里不会被回答；**第二，MARITIME-HF 与 MARITIME-CV 才是它真正的价值所在**——肥胖药物最终要证明的不是体重数字，而是心衰住院与心血管事件。这也是本期最该被记住的结构性变化：**减重药的下半场，终点已经从「体重」迁移到「心衰与事件」**。

## 🔧 其他动态

- **《肥胖患者的长期体重管理及药物临床应用指南（2026 版）》**（中华医学会内分泌学分会）：仍在书目登记阶段（⚠️ 全文逐条比对未完成），本期不复述推荐；其「分阶段个体化减重目标」与「老年、肝肾功能不全人群用药原则」是后续专项对照的重点。
- **国内市场规模口径**（行业估计，⚠️ 非官方统计）：2026 年中国 GLP-1 整体市场约 **230 亿–450 亿元**，2030 年有望突破千亿元——**该区间跨度极大，仅作背景，不作测算依据**。
- **T2DM 侧线无新增**：本期两款药均以**体重管理**为申报/登记适应症，糖尿病适应症（HDM1002 中国 Ⅲ 期、MariTide 全球 Ⅲ 期）均未读出。
- **临床落地提醒**：① 卡维列隆**尚未获批**，患者不可自行获取；② 正在使用注射类 GLP-1 或 GIP/GLP-1 双靶点药物者，**不建议自行切换**到任何口服小分子——剂量体系不可换算；③ 本期两款药的**中国定价与医保身份均未知**。
